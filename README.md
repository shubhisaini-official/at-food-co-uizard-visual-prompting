## 📌 Executive Summary

* **Objective:** Establish the low-fidelity mobile application wireframe for **AT Food Co.’s** *Dog Life Record* app using **Uizard AI**, transforming natural language UI descriptions into structured wireframe components.
* **Primary Output:** Mobile wireframe layout defining daily caloric tracking, meal plan selection, and subscription onboarding.

---

## 📝 1. Visual Prompt Engineering Framework

    Prompt Tier          | Prompt Text Structure                                                                                                  | Output Quality
    ---------------------|-------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------
    Bad (Vague)          | "Create a dog food app website"                                                                                         | Unstructured, generic template layout
    Good (Specific)      | "Mobile app for fresh dog food delivery with hero banner, 3 feature cards, pricing tiers, and email signup"             | Standard section layout with placeholder text
    Great (Structured)   | "Mobile app for AT Food Co. Dog Life Record. Header: 'Today's Caloric Goal'. Progress ring: 80% complete. List items: Morning Meal (Checked), Evening Meal. CTA: '+ Log Meal'. Style: Minimalist, Forest Green (#2E7D32) and Snow White (#FDFBF7), Reference: Linear.app" | High-accuracy low-fidelity interactive UI wireframe

## 📱 2. Mobile App Section-by-Section Layout Specs

    UI Section           | Component Breakdown                                  | Functional Purpose
    ---------------------|------------------------------------------------------|-------------------------------------------------------
    Header Module        | App Title: "Dog Life Record" + Profile Avatar        | Identifies active dog profile (e.g., "Bruno - Golden Retriever")
    Progress Dashboard   | Circular Ring Widget (80% Caloric Target Completed)  | Instant visual status of daily human-grade nutrition
    Interactive Checklist| Checkbox items for Morning Fresh Meal & Water Intake | Encourages daily user retention and app engagement
    Bottom Action Bar    | Floating Action Button (+ Log Meal / Order Fresh)    | High-converting primary CTA for meal subscription reorders

---

## ⚙️ 3. Step-by-Step Uizard Execution Protocol

1. Initialize Uizard AI workspace and select "Generate with AI".
2. Input structured UI prompt specifying headers, progress rings, checklist items, and color guidelines (#2E7D32 Forest Green).
3. Generate wireframe components in 30 seconds.
4. Customize drag-and-drop elements, fine-tune typography hierarchy (Inter sans-serif), and adjust element padding.
5. Export wireframe specs as SVG/PNG assets and HTML/CSS layout references.

---

## ⚡ 4. Real-World Execution Critique

* **Pros:** Translates product ideas into tangible UI wireframes in seconds, saving hours of manual Figma sketching.
* **Limitations:** Generates wireframe layouts only; interactive backend logic and dynamic database connections must be wired in Softr, Framer, or Airtable.
